# Pliki piosenek

Pliki audio `.mp3` dodawaj do folderu `audio/`. Ich nazwy muszą odpowiadać ścieżkom zapisanym w `db/seed.sql`, np. `audio/melodia-nocy.mp3`. Używaj małych liter, myślników zamiast spacji i zapisuj nazwy bez polskich znaków.

Pliki LRC dodawaj do folderu `lrc/`. Nazwa pliku LRC powinna odpowiadać nazwie pliku audio, ale mieć rozszerzenie `.lrc`.
